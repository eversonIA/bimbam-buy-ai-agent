# Entregáveis do Challenge Alura Agente

Para concluir corretamente o desafio, a sua entrega deve incluir os seguintes elementos:

## Repositório no GitHub

Um repositório público no GitHub com o código-fonte do seu projeto.
Um histórico de commits que reflita o desenvolvimento do projeto.
Uma estrutura organizada e fácil de compreender.

## Documentação (README)

O seu repositório deve incluir um arquivo README que contenha:

Uma descrição geral do projeto.
A arquitetura da solução implementada.
As tecnologias e ferramentas utilizadas.
Instruções para executar o projeto.
Exemplos de perguntas que o agente consegue responder.
Exemplos de respostas geradas pelo agente.

## Agente Inteligente Funcional

Um agente de inteligência artificial capaz de responder a perguntas baseadas no conteúdo de um documento (PDF ou CSV).
Código para ler e processar o documento utilizado como fonte de informação.

## Evidência do Deploy na OCI (ou qualquer outro serviço nuvem como Vercel, Render, Streamlit, ou o que for mais acessível. Disponível com uma url público.)

Você deve demonstrar que a sua aplicação foi implantada (deploada) e está funcionando na nuvem.
Você pode incluir:

O link público da aplicação em funcionamento.
Uma captura de tela (print) que mostre a aplicação sendo executada corretamente.
